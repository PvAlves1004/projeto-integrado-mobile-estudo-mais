\# Testes



Por padrão do Gradle Android, os testes ficam dentro do módulo `app`:



\- \*\*Unitários:\*\* `app/src/test/`

\- \*\*Instrumentados / UI (Espresso):\*\* `app/src/androidTest/`



Esta pasta é reservada para scripts e artefatos de teste auxiliares (planos de teste, dados de exemplo, relatórios).
